# ExactKB

### An Image Compressor & Quick Editing Website

ExactKB is a **client-side image compression and quick editing web application** that allows users to compress images to a specific size (in KB) while also applying basic photo enhancements. All processing happens **inside the browser**, meaning **images are never uploaded to a server**, ensuring privacy and fast performance.

---

## 🚀 Features

### 📦 Image Compression

* Compress images to a **specific target size (KB)**.
* Supports **WebP, JPEG, and PNG** formats.
* Uses **binary search quality optimization** to reach the desired file size.
* Automatically **downscales images** if required to meet the target size.

### 🎨 Quick Photo Editing

* **Brightness adjustment**
* **Contrast adjustment**
* **Saturation control**
* **Blur effect**
* **Sharpen / Unblur enhancement**

### ⚡ Enhancement Tools

* **Auto Enhance** for quick improvement
* **Reset Filters** to revert adjustments
* **Revert to Original Image**

### 🖼 Preview System

* Live **canvas preview**
* Shows **image dimensions**
* Real-time preview before download

### 🌙 UI Features

* **Dark / Light mode**
* Responsive layout
* Simple and clean interface

---

## 🔒 Privacy

ExactKB works **100% in the browser**:

* No server uploads
* No image storage
* No tracking

Your images **never leave your device**.

---

## 🛠 Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Canvas API**

Image processing is handled using the **HTML5 Canvas API** with custom compression and filtering algorithms.

## 📥 How to Use

1. Open the website.
2. Upload an image.
3. Adjust editing options if needed.
4. Set the **target size in KB** or adjust quality.
5. Click **Compress & Download**.
